# m48t59y_rpi_kcd

Diseño de PCB en KiCad para interfaz M48T59Y (RTC/NVRAM) con PIC18F.

## Estructura

- `m48t59y_pic18f.kicad_pro` - Proyecto principal
- `m48t59y_pic18f.kicad_sch` - Esquemático principal
- `m48t59y_pic18f.kicad_pcb` - Layout PCB

## Módulos

- `power.kicad_sch` - Alimentación
- `mcu.kicad_sch` - Microcontrolador PIC18F
- `m48t59y.kicad_sch` - Circuito M48T59Y
- `txs0108e.kicad_sch` - Traductor de niveles TXS0108E
- `oled.kicad_sch` - Display OLED
- `led_sw.kicad_sch` - LEDs y switches
- `uart.kicad_sch` - UART
- `xt.kicad_sch` - Cristal
